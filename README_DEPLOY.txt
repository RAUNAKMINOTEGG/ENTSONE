IMPORTANT
OTP is DEMO mode now: the OTP is generated by the backend and shown in the user app; no SMS is sent. Later set OTP_MODE=vonage and provide Vonage credentials.
Payment/wallet actions remain DEMO ONLY and do not process real money.
Tournament data, registrations, results, notifications, room credentials, admin controls, match start time, countdown settings, maps and rules are server/database backed.

COUNTDOWN
Admin can set an exact Match Start Time, enable/disable countdown, and choose how many hours before the match the countdown becomes visible (default 24 hours).

DO NOT delete or recreate the existing PostgreSQL database.


CURRENT RELEASE
- User app opens on the tournament Home page; login/signup is opened from the profile/login button.
- OTP is DEMO ONLY and generated by the backend; Vonage quota/credentials are not used in this release.
- Payment/wallet is DEMO/disabled; no real money is charged.
- After successful signup/login, the user profile is connected to the PostgreSQL user and the app returns to Home.
