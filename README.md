# ENTSONE

Professional eSports tournament website frontend.

## Included
- 10 games
- Live/upcoming tournament cards
- Prize pool and entry fee
- Slots and tournament modes
- Login/Signup UI
- Mobile bottom navigation
- Professional eSports design
- Games/Tournaments filtering
- Tournament join flow frontend

## Important
This is the frontend version. OTP verification, real payment gateway, wallet ledger,
database, and production admin backend are not connected yet.
